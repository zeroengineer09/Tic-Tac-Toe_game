# 🎮 Tic Tac Toe — Zero Engineer

A modern, lightweight, and interactive Tic Tac Toe game developed under the **Zero Engineer** brand. Enjoy the timeless X and O strategy game with a clean user interface, smooth gameplay, and a simple, user-friendly experience.

Whether you're playing for fun or challenging a friend, Tic Tac Toe is a great way to test your logic, strategy, and decision-making skills.

## ✨ Features

- 🎯 **Classic Gameplay** — Enjoy the traditional Tic Tac Toe experience.
- 👥 **Two-Player Mode** — Play against a friend on the same device.
- 🧠 **Strategic Thinking** — Plan your moves and outsmart your opponent.
- 🏆 **Win Detection** — Automatically detects winning combinations.
- 🤝 **Draw Detection** — Recognizes when the board is full without a winner.
- 🔄 **Restart Game** — Start a new match whenever you want.
- 🎨 **Modern UI** — Clean, minimal, and visually appealing interface.
- ⚡ **Responsive Controls** — Enjoy smooth and intuitive interactions.
- 📱 **Mobile-Friendly** — Designed for a comfortable experience on supported screen sizes.

## 🎮 How to Play

1. Start a new game.
2. Player X makes the first move.
3. Players take turns placing X and O in empty cells.
4. Match three symbols horizontally, vertically, or diagonally to win.
5. If all nine cells are filled without a winning combination, the match ends in a draw.
6. Restart the game to play again.
